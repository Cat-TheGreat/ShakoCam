8/01/2026-Breakthrough Day! Feeling down since the recorder didn't even activate during rehearsal, so I went and tried getting the simplest possible video recorder going. This is when I dug around in the files of the first ever video I took, the single frame one, and found that the project I used had a folder called a decoder. Thus I did some research and through freeconverter.com I turned the one frame video into a multiple frame video! So I discovered I could just take the really simple example video recorder and put that file through a decoder and get real video. So with the help of Gemini I made a WebApp for it since the ESP32S3 has a wifi network, and I got it to control the LED with my phone which was so cool. Then, I got it to be able to press a button to my phone and save a .txt file to the SD card. Finally, I got Gemini to merge the very simple video code with the web app code to create a web app that stopped and started recording from my phone. Then, added a gallery so you can select videos and view them using the web app's decoder. Very proud.
